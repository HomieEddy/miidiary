    **1. `theme/tailwind.config.js` — add dark mode color tokens (D-21):**
    The config already has `darkMode: "class"`. Extend the `theme.extend.colors` section to add dark variants. In NativeWind v4, the cleanest way to get dark mode is with CSS custom properties in `global.css` or `globals.css`. Add to `global.css`:
    ```css
    .dark {
      --background: 30 26 36;       /* #1E1A24 */
      --card: 42 38 49;             /* #2A2631 */
      --foreground: 245 240 235;    /* #F5F0EB */
      --border: 74 69 80;          /* #4A4550 */
      --muted: 48 44 56;           /* #302C38 */
    }
    ```
    This CSS-variable approach means the existing `bg-background`, `bg-card`, `text-foreground` etc. classes automatically get dark values when the `dark` class is on the root — no need to add `dark:` prefixes to every component. Verify that `theme/tailwind.config.js` uses `hsl(var(--background))` format or add it if missing.

    If the tailwind.config colors are NOT in `hsl(var(...))` format but are hardcoded hex: instead, keep the existing light-mode hardcoded colors and add explicit `dark:` utilities in tailwind.config `theme.extend`:
    ```js
    // Add under theme.extend.colors:
    // The dark palette colors as separate tokens (e.g. "background-dark", "card-dark")
    // Then in each screen, add dark: prefixed classes manually
    // This is the fallback approach if CSS variables aren't working
    ```

    Use whichever approach matches what is already in `global.css` / `tailwind.config.js` — read both files and choose the consistent path. Do NOT break existing light-mode colors.

    **2. `src/hooks/useTheme.ts` — dark mode hook:**
    ```typescript
    import { useColorScheme } from "react-native";
    import { MMKV } from "react-native-mmkv";
    import { useEffect, useState } from "react";

    const storage = new MMKV({ id: "theme" });
    const THEME_KEY = "theme_override";

    type ThemeOverride = "system" | "dark" | "light";

    export function useTheme(): {
      isDark: boolean;
      themeOverride: ThemeOverride;
      setThemeOverride: (mode: ThemeOverride) => void;
    } { ... }
    ```
    Logic:
    - Read system color scheme with `useColorScheme()` (returns "dark" | "light" | null)
    - Read MMKV `THEME_KEY` on mount
    - `isDark = override === "dark" || (override === "system" && systemScheme === "dark")`
    - `setThemeOverride` saves to MMKV and updates local state

    export function ShimmerView({ className }: { className?: string }): ReactElement {
      const opacity = useSharedValue(0.4);
      useEffect(() => {

    }
