# Plan 03-02: On-Device Classification

## Objective
Implement on-device entry classification (Diary/Task/Note) using lightweight model inference with deterministic heuristic fallback.

## Tasks

1. Create `classificationService` with primary on-device model path and fallback heuristics.
2. Return confidence and rationale metadata for debugging and manual override support.
3. Integrate classification into transcription pipeline before persistence.
4. Add tests for category correctness and fallback behavior when model inference is unavailable.
