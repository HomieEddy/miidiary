## Cross-Phase Integration

Wiring verified end-to-end (scout report, code-grounded):

1. **Record → persist → browse**: HomeScreen → useAudioCapture (audioCaptureService, expo-audio) → useTranscription.processRecording → transcriptionService (whisper.rn + modelManager) → classificationService → entriesRepository.createEntry (Realm v3 / web in-memory) → entriesStore.addPersistedEntry → Diary/Tasks screens reload via latestPersistedEntryId effect. ✓
2. **Search**: useEntries searchQuery → debounced entriesRepository.searchEntries (Realm `CONTAINS[c]`, web lowercase includes), category-scoped. ✓
3. **Task toggle**: TasksScreen → entriesRepository.toggleComplete → EntryRecord.isCompleted → reload. ✓
4. **Theme**: useTheme shared store (useSyncExternalStore) → root layout `dark` class + tab bar palette. ✓
5. **Security**: BiometricGate wraps root Stack; wipe-all requires reauthenticateForDestructiveAction (web-guarded). ✓
6. **Background**: setBackgroundProcessors + backgroundTaskService.defineTask('miidiary.background.transcription') with registerTaskAsync. ✓
7. **Web fallbacks**: repository/modelManager/secureStorage/transcription `*.web.ts` resolve; Realm/keychain never load on web. ✓
