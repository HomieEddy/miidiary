  <files>src/services/entriesRepository.ts</files>
  <behavior>
    - searchEntries("") returns all entries (same as listChronological)
    - searchEntries("coffee") returns only entries whose text contains "coffee" (case-insensitive)
    - searchEntries("  ") (whitespace-only) returns all entries
    - toggleComplete(id) flips isCompleted: false → true, true → false
    - toggleComplete(unknown-id) is a no-op (no throw)
    - updateEntry patches text, category, title, re-derives previewText, updates updatedAt
  </behavior>
  <action>
    Add these three methods to entriesRepository (before the export object):

    1. `searchEntries(query: string): Promise<EntryRecord[]>`:
       - Trim the query. If empty after trim, call and return `listChronological()`.
       - Otherwise: use Realm's `filtered()` with a case-insensitive CONTAINS query on the `text` field:
         ```typescript
         realm.objects<RealmEntry>("Entry").filtered("text CONTAINS[c] $0", query.trim())
         ```
       - Sort by queryKey (same as listChronological). Return mapped EntryRecord[].

    2. `toggleComplete(id: string): Promise<void>`:
       - Get realm instance. `realm.objectForPrimaryKey("Entry", id)`.
       - If null, return early (no throw).
       - In `realm.write(() => { entry.isCompleted = !entry.isCompleted; })`.

    3. `updateEntry(id: string, patch: UpdateEntryPatch): Promise<EntryRecord>`:
       - Import `UpdateEntryPatch` from `@/types/entry`.
       - Import `deriveEntryPreview` and `deriveEntryTitle` from `@/utils/entryTextDerivation`.
       - Get realm instance. Find entry by id. If not found throw `new Error(\`Entry ${id} not found\`)`.
       - In `realm.write()`: apply patch fields, update `updatedAt = new Date()`.
       - If `patch.text` is provided and `patch.title` is NOT provided: auto-derive title with `deriveEntryTitle(patch.text)`.
       - Always re-derive `previewText` from the final `text` value.
       - Return `toEntryRecord(entry)`.

    Also update the inline `RealmEntry` type to include `isCompleted: boolean`.

    Export the new methods in the `entriesRepository` object.
