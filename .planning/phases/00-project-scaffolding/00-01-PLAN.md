<name>Task 3: Configure NativeWind v4, create src/ directory structure, bundle font TTF files</name>
<read_first>@AGENTS.md @theme/tailwind.config.js</read_first>

<action>
Per D-03, D-04, D-09, D-10:

A) Configure NativeWind v4:
1. Add `plugins: ['nativewind/babel']` to `babel.config.js`. The existing preset `babel-preset-expo` must remain. The `plugins` array should come after the `presets` array. Result pattern: `module.exports = function(api) { api.cache(true); return { presets: ['babel-preset-expo'], plugins: ['nativewind/babel'] }; };`
2. Create `app/global.css` (at project root) with the following content — exactly 3 Tailwind directives:
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;
   ```
3. Create `nativewind-env.d.ts` (at project root) for TypeScript NativeWind support. Content:
   ```typescript
   /// <reference types="nativewind/types" />
   ```
4. The existing `theme/tailwind.config.js` already contains the full color palette, font families, and presets (nativewind/preset). It will be referenced from the project during the next plan (00-02) — do NOT move or copy it now. It stays at `theme/tailwind.config.js`.

B) Create src/ directory structure per D-03 and AGENTS.md §2.3:
1. Create ALL of the following directories. Each must exist with no files inside (per D-04 — no placeholder barrel files, no .gitkeep):
   - `src/app/`
   - `src/screens/`
   - `src/components/ui/`
   - `src/services/`
   - `src/stores/`
   - `src/hooks/`
   - `src/utils/`
   - `src/types/`
   - `src/assets/icons/`
   - `src/assets/fonts/`
   - `src/assets/images/`

C) Bundle font TTF files per D-09, D-10:
1. Download Nunito font files for weights: 400, 500, 600, 700, 800, 900 (regular, medium, semibold, bold, extrabold, black). URL pattern: `https://github.com/google/fonts/raw/main/ofl/nunito/Nunito-{Weight}.ttf`
   - Weights: `Regular` (400), `Medium` (500), `SemiBold` (600), `Bold` (700), `ExtraBold` (800), `Black` (900)
2. Download Fredoka font files for weights: 500, 600, 700. URL pattern: `https://github.com/google/fonts/raw/main/ofl/fredoka/Fredoka-{Weight}.ttf`
   - Weights: `Medium` (500), `SemiBold` (600), `Bold` (700)
3. Download Playfair Display font files for weights: 400, 700. URL pattern: `https://github.com/google/fonts/raw/main/ofl/playfairdisplay/PlayfairDisplay-{Weight}.ttf`
   - Weights: `Regular` (400), `Bold` (700)
4. Download JetBrains Mono font files for weights: 400, 700. URL pattern: `https://github.com/google/fonts/raw/main/ofl/jetbrainsmono/JetBrainsMono-{Weight}.ttf`
   - Weights: `Regular` (400), `Bold` (700)
5. Place all downloaded .ttf files directly into `src/assets/fonts/`. Naming convention: `{FontName}-{Weight}.ttf` (e.g., `Nunito-Bold.ttf`, `Fredoka-Medium.ttf`)
6. If Google Fonts direct GitHub URLs are unavailable, use the Google Fonts CSS API as fallback: `https://fonts.googleapis.com/css2?family=Nunito:wght@400;500;600;700;800;900&family=Fredoka:wght@500;600;700&family=Playfair+Display:wght@400;700&family=JetBrains+Mono:wght@400;700` — parse the `src: url(...)` entries from the response to get download URLs.
7. If any font file download fails, create a placeholder error log at `src/assets/fonts/DOWNLOAD-ERRORS.txt` listing which files failed, and continue — the other font files will still be usable. The failed ones can be manually downloaded later.
</action>
